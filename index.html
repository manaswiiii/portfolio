Negative result

Learned patch ordering (REOrder) for 3D brain MRI: a rigorous negative result

I implemented a published RL method for 3D MRI from scratch, tested it across about 40 runs and 3 architectures, and showed that its apparent gain was measurement noise.

Question
REOrder learns the order in which image patches are fed to a transformer. It was published for 2D images. Does it still help when extended to 3D volumetric MRI for Alzheimer's classification on ADNI?
What I built
I implemented REOrder in PyTorch: a Plackett–Luce policy over patch permutations, trained with REINFORCE under an EMA baseline and a Gumbel-temperature curriculum, extended from 2D to 3D volumetric MRI.
How I tested it
I benchmarked it against nine fixed orderings across three transformers spanning a 268× capacity range (0.33M–88.4M parameters). That came to ~40 experiments on an 8× V100 HPC cluster, with subject-level splits to prevent leakage.
Result

The learned ordering did not beat a well-chosen fixed ordering, and I traced each architecture's null result to a distinct mechanism:

  • Full 3D ViT: it's order-sensitive only through positional embeddings, so it can't benefit from a policy that's resampled every batch.
  • 0.33M model: undertrained at the available compute budget.
  • Hierarchical model: the apparent gain came from block-locality structure, not from any learned permutation.
The part I'm proudest of
One configuration showed an apparent +7.5-point gain. A 2×2 ablation and seed-variance analysis isolated it to measurement noise, not a real improvement.

Rotary Position Embeddings in 3D Vision Transformers for Alzheimer's classification

I integrated Rotary Position Embeddings (RoPE) into 3D Vision Transformers for Alzheimer's classification on ADNI T1w MRI. I implemented the MiNiT and NiT variants and benchmarked them against a ViT-B/16 baseline across pretraining regimes on 44K UK Biobank and 100K synthetic LDM volumes, reaching AUC 0.921 on ADNI, with 0.887 and 0.813 zero-shot on the independent NIMHANS and OASIS3 cohorts.

ML · LLM evaluation

Chain-of-Thought Faithfulness Analysis

A 4-experiment framework (~15K LLM queries) testing whether chain-of-thought causally drives predictions. CoT improved math reasoning by 44–50 pp, while science MCQ showed 83% early-answer consistency, indicating post-hoc rationalization. It also identified a “Steered-But-Hidden” failure mode, in which models silently follow misleading prompt hints while emitting reasoning that never acknowledges the steer (16% on ARC-Challenge with Qwen 2.5).

Systems · Infrastructure

Distributed Rate Limiter & API Gateway

A horizontally-scalable API gateway enforcing token-bucket and sliding-window rate limits over Redis-backed shared state, with limit checks run as atomic Lua scripts to eliminate cross-replica read-modify-write races. Result: under k6 load across three replicas behind nginx, in-process limiting over-admitted ~3× the configured rate while the Redis-backed limiter held. Also includes Prometheus and Grafana instrumentation, fail-open/fail-closed behavior on Redis loss, and pytest concurrency tests in CI.
